# Rock Paper Scissors Game

A simple rock paper scissors game written in Python.

## How to Play

1. Run the game:
   2. Choose your move:
   - s for rock (سنگ)
   - k for paper (کاغذ)
   - g for scissors (قیچی)

3. The computer will choose randomly and the winner will be announced.

4. You can play multiple rounds!

## Features

- Play against the computer
- Multiple rounds
- Persian (Farsi) language support
- Simple and fun

- Python 3
